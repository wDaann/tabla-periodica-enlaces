# Tabla Periodica y Enlaces Quimicos

Aplicacion interactiva desarrollada con Python y Flet para consultar elementos, confirmar combinaciones y clasificar enlaces quimicos.

## Ejecutar localmente

```powershell
.venv\Scripts\python.exe main.py
```

## Instalar dependencias

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```
